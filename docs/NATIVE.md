# 原生界面与守候恢复（1.1.0）

应用的守候、时段、声音、设置、历史和响铃页面均使用 Kotlin / Jetpack Compose 原生控件。运行时不创建 WebView，旧网页资源也不打入原生 APK。

## 外观

打开“设置 → 外观与个性化”：

- 选择十二种预设色，或用 HEX / RGB 调整任意主题颜色。按钮、开关、选中状态与卡片配色同步变化。
- Android 12 及以上可启用动态颜色，使用系统壁纸配色。关闭后恢复自选颜色。
- 支持浅色、深色、跟随系统和 AMOLED 纯黑模式。
- 通过系统文件选择器设置背景图片。无需整个相册的读取权限，最大 20 MB，复制到应用内部，最长边缩放至不超过 1920 像素。
- 背景遮罩与卡片不透明度可调；可以移除背景。

图片与铃声不上传。自选背景独立保存在本机，当前 JSON 备份不包含图片或音频本身。

## 最近任务隐藏

“设置 → 后台守候 → 从最近任务隐藏”使用 Android 的 AppTask.setExcludeFromRecents 公共接口。开启后隐藏本应用任务卡片，关闭后恢复；桌面图标、守候通知和停止按钮继续保留。

该设置用于减少误划卡片，并非后台保护权限，也不能阻止系统强制停止、厂商一键清理或内存回收。不要把它当作“锁定后台”。

## 守候恢复

继续使用原有前台服务、持续通知、START_STICKY、网络重连重试、时段边界闹钟与可选无障碍辅助。新增独立的、约每 15 分钟触发的非精确定时恢复检查：守候已启用而服务不在运行时请求恢复。

系统休眠可能推迟检查，系统也可能拒绝后台启动；页面与记录会保留实际状态。主动停止守候时取消恢复检查，不会主动重新开启。关闭“定时恢复检查”只关闭该补充机制。

外观与最近任务设置不会改变检测间隔、重设直播场次或主动重启服务。直播检测仍使用原生后台，界面改动不改变提醒时段、接口解析、场次去重和音频播放逻辑。

## 安装与迁移

CI 输出 `ManquAlarm-1.1.0-native-preview.apk`，包名为 `dev.hazel.livealarm.preview`，桌面名称为“满区闹钟·原生预览”。它是独立调试签名的预览版，可以与 1.0.5 并排安装，不覆盖旧版。

需要迁移设置时，在旧版导出 JSON 备份，再在原生预览版导入；重新选择自己的铃声，并按系统提示配置新应用的通知与后台权限。只在准备使用的一版中开启守候，避免两版同时提醒。

正式发行配置仍使用 `dev.hazel.livealarm` 和原有 `hazel` 设置文件。覆盖正式版需要原发行签名私钥；私钥不在公开仓库，CI 不持有它。

## 验证

现有 36,063 项纯 Java 规则断言继续运行。新增 Android 设备测试检查原生页面、配色保存、时段编辑、背景导入、最近任务开关、停止守候后的恢复取消和原生响铃流程。具体成功结果以对应 GitHub Actions 运行记录为准。

模拟器中的音频启动与通知登记不等于真实手机可以听到、锁屏可以显示或整夜检测不中断。真实开播、各厂商清理行为与长时间待机仍需要设备验证。
